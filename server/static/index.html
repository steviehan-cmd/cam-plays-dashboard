Rules for every play

  1. Candle close decides. Fails, cancels and "price has gone beyond" checks use the 1-minute close. Entries and targets trigger when price reaches them.
  2. Stop = 1.5 × the 5-minute ATR (the average 5-minute candle) beyond the entry pivot, the same for every play. The size is fixed when the play starts.
  3. If the entry candle already closes beyond the stop, the play does not start.
  4. Target zone: getting within 5% of the entry-to-target distance counts as a target hit.
  5. CPR filter: H days allow H plays, L days allow L plays (a neutral day allows both). Narrow CPR allows B, C, D. Wide CPR allows A, E. F plays run at any width.
  6. Settings: one stop size (default 1.5 × ATR) and one target zone (default 5%) for all plays. Only the entry buffer is set per play.
  7. Everything resets when the new session starts at 18:00 New York.
